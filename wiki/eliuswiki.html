EliusWiki is a personal encyclopedia about Elius. It is built as a static website with plain HTML, CSS, and JavaScript, and is designed to be fast, readable, and easy to maintain.

Purpose

Most personal information online is scattered across profiles, captions, and messages. EliusWiki gives that information a stable address and a structure: a lead section, a few clear headings, and references for the facts that can be checked.

The wiki is not intended to be a complete biography. It is a public notebook with encyclopedia manners — small enough to read in one sitting, structured enough to grow.

Design

The visual language is paper and ink: a warm neutral background, a serif for headings, a sans-serif for body text, and a single cobalt blue for links. A vermilion accent marks the details that matter — the logo dot, the active tab, and the open sections.

The layout follows a familiar wiki pattern: a persistent sidebar, an article header with tabs, a table of contents, an infobox, and references. It is responsive, supports a dark theme, and keeps the reading column narrow enough to be comfortable.

Technical notes

The site is entirely static. There is no build step, no framework, and no database. The pages are hand-written HTML; assets/css/wiki.css holds the design system; assets/js/wiki.js adds search, theme switching, the mobile menu, and table-of-contents highlighting.

Search is client-side. The index lives in assets/js/search-index.js and is small enough to load with the page. The site can be hosted on GitHub Pages, Cloudflare Pages, Netlify, Vercel, or any static file server.

Contributing

Corrections, additions, and project entries are welcome by email. Send a short note with the page you are correcting and, where possible, a link that supports the change.

Domain and hosting

The intended canonical domain is elius.wiki. At the time of the build, a public RDAP lookup returned no registration record for the name, which suggests it may be available; availability should be confirmed with a registrar before purchase.

The project includes a CNAME file for GitHub Pages and is ready for any static host. Once the domain is registered, point it at the host and enable HTTPS. The canonical URLs, sitemap, and Open Graph metadata already use https://elius.wiki.
